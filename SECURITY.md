# Security

Please report suspected security issues privately to security@stackradar.com.

Do not open public issues for vulnerabilities or disclosure-sensitive reports.

Please include:

- the affected action version, release tag, or commit
- reproduction steps or proof-of-concept details
- the security impact you believe is possible
- whether the issue affects action inputs, OIDC handling, CLI installation,
  release verification, or upload behavior

We will acknowledge valid reports, investigate privately, and coordinate a fix
and disclosure timeline appropriate to the impact.
